# 《星溯旅者》Star Trace Voyager

> 二次元多结局养成网页游戏 · 轻养成 + 剧情分支 + 回合微战斗 + 好感度结局系统

## ✦ 快速开始

```bash
npm install     # 安装依赖
npm run dev     # 开发预览  → http://localhost:5173
npm run build   # 生产构建  → dist/（任意静态服务器可托管）
npm run preview # 预览生产包 → http://localhost:4173
npm run validate# 剧情数据链完整性校验（152节点/38收集/8结局）
```

## ✦ 工程结构

```
src/
├── data/            # 全部游戏数据（角色/剧情/战斗/结局/图鉴）
│   ├── characters.js
│   ├── battles.js
│   ├── codex.js
│   ├── endings.js
│   ├── story.js         # 剧情汇总入口
│   └── stories/         # 序章 + 四条角色线节点图
├── game/
│   ├── store.jsx        # useReducer + Context 全局状态
│   ├── save.js          # localStorage 持久化
│   └── toast.jsx        # 轻量通知系统
├── components/
│   ├── Portrait.jsx     # 参数化 SVG 动漫立绘（4角色×6表情）
│   ├── Starfield.jsx    # Canvas 星空粒子（星点/流星/光尘）
│   ├── SceneBG.jsx      # 五套场景氛围层
│   ├── CGCard.jsx       # 回忆片段 CG 卡
│   └── EnemySprite.jsx  # 暗蚀敌人精灵
├── screens/             # 标题/选人/剧情/战斗/好感/图鉴/结局
└── scripts/validate.mjs # 数据链完整性校验脚本
```

## ✦ 简历项目介绍（可直接使用）

**项目名称**：《星溯旅者》二次元多结局养成网页游戏

**项目简介**：基于 React 19 + TailwindCSS 独立开发二次元剧情养成网页小游戏。项目包含多角色人设、分支剧情系统、好感度数值养成、轻量化回合战斗、图鉴收集、八结局剧情闭环。采用玻璃拟态二次元 UI 与星空粒子动态特效（Canvas 星空 + SVG 矢量立绘，零图片资源、首屏 gzip 约 122KB），实现沉浸式交互体验。全程由 AI 辅助逻辑开发、UI 搭建与 bug 调试，完整掌握前端状态管理、动态渲染、交互游戏开发流程。

**技术亮点**：
- 自研节点图剧情引擎（152 节点 / 8 战斗 / 8 结局），配套数据链完整性校验脚本，保证剧情零死路
- 参数化 SVG 立绘系统：统一脸模 + 角色发型/配色/饰品参数化 + 6 种表情，风格绝对统一且任意分辨率清晰
- useReducer + Context 状态机驱动 7 大界面路由，localStorage 自动存档、跨周目好感保留
- Canvas 星空粒子背景（星点闪烁/流星/上升光尘）+ 玻璃拟态 UI + 打字机/章节卡/伤害飘字等微动效
